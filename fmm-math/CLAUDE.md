# nd-fmm-math

Purpose: Legendre functions, real solid harmonics and gradients, rotation blocks,
index layout and the scalar trait that every other nd-fmm-* crate builds on.
Phase and components: Phase 0, C0.1–C0.3 (tasks T2, T4, T5 in docs/phase0/).
Helmholtz CH1.2a added `orthonormal` (CONVENTIONS §3.15): the normalised Legendre
functions of spike S1 (telescoped near the poles, an exponent per column), the real
orthonormal harmonics with ∂θ and (1/sin θ) ∂φ, and the rotation blocks at any degree
(Gumerov–Duraiswami y-blocks, the π − β signs, z-y-z blocks); its tests are
`tests/orthonormal/` (degrees above 300 ignored, run in release). CH1.2b and CH1.2c add
the radial functions and the coaxial coefficients.

## Rules
- Read docs/CONVENTIONS.md before changing any formula; never change a convention here.
- Generic over T: RealScalar; no allocation in hot paths (write into caller slices).
- No trigonometric functions in harmonic evaluation (CONVENTIONS §3.5).
- Before finishing: `cargo clippy -p nd-fmm-math --all-targets -- -D warnings`
  and `cargo test -p nd-fmm-math` must pass.

## Allowed dependencies
num-traits; dev-dependencies: proptest, approx, serde_json (fixture loading).
Anything else needs a note in the PR.

## Test oracle
Fixtures in fmm-math/fixtures/ (generated by tools/fixtures/), plus the identities in
CONVENTIONS §3.4 and the rotation properties in §3.8. For `orthonormal`,
`fixtures/helmholtz_angular.json` (`tools/fixtures/gen_helmholtz_angular.py`), the
identities of §3.15, and the Laplace harmonics and blocks conjugated by N at p ≤ 30.
