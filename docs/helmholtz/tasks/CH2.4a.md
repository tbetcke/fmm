# CH2.4a The vectorised exponential

Started 2026-10-31 on `tbetcke/h-ch2-4a`. Roadmap: "CH2.4 Yukawa P2P in `nd-fmm-simd`" (H2;
seventh on the priority list), split on 2026-10-31 into CH2.4a (this task) and CH2.4b.
Proposal: §10 CH2.4; §2 (constraint 1), §5.5, §5.7, §6.1, §6.2.

## Goal

The exponential e^x for x ≤ 0, in `nd-fmm-simd`'s vector layer on every ISA and in both
precisions, with an accuracy contract checked on real hardware and a public slice function
for tests and reports. It is CH2.4b's e^{−κr}, as the inverse square root of Phase 3S T4
(C3S.3) was T5's.

## Acceptance (proposal §10, verbatim)

CH2.4's, of which this sub-task prepares the first item:

> an accuracy contract like simd-p2p.md's; cost per pair against Laplace; Laplace P2P bit
> for bit unchanged and at least 90 % of the spike (C3S.4)

CH2.4a's own *Done when* (the split, roadmap):

- e^x within 4 u_T relative on the domain [x_min, 0] on every ISA a machine offers, with
  x_min = −(e_max − 1) ln 2 rounded inward (about −708.39 in f64 and −87.33 in f32), so that
  every result is a normal number: f32 exhaustively over the domain, f64 on 10⁷ seeded
  samples plus the domain ends, −0 and +0 giving exactly 1;
- below x_min (and at −∞) a result in [0, 2^(e_min)], never NaN, never negative;
- each value's result independent of its position and of the slice length (whole vectors
  in place, the tail in a padded copy, as `rsqrt_slice`);
- no call in the inner loop of any entry point (the release disassembly), and its
  instruction count reported;
- Laplace untouched: the P2P, matrix and wave entry points' inner loops the same
  instruction for instruction as `main`'s on aarch64 and x86_64 (the existing layer
  methods are not changed, only new ones added).

## Changes

`nd-fmm-simd` only, plus docs. No manifest, dependency, convention or `nd-fmm-plan` change.

- `src/arch/mod.rs`: `Simd` gains the operations the exponential needs, added beside the
  existing ones, which stay as they are:
  - `max(a, b)` (the clamp to x_min);
  - `scale_pow2(x, k)`: x · 2ⁿ, for k = n + c holding the integer n in its low mantissa
    bits (c = 1.5 · 2^(mantissa bits), the round-to-nearest constant), by adding
    n · 2^(mantissa bits) to x's bits; valid where the result is normal. NEON
    `vshlq_n_s64`/`vaddq_s64` (`_s32` for f32), AVX2 `_mm256_slli_epi64`/`_mm256_add_epi64`
    (`_epi32`), AVX-512 the 512-bit forms, the scalar layer `to_bits`/`from_bits`.
  - `exp_body`, generic over `Simd`, and an `exp` method with a default body on the trait:
    x ← max(x, x_min); k = fma(x, 1/ln 2, c) (round to nearest); n = k − c;
    r = fnma(n, ln2_hi, x); r = fnma(n, ln2_lo, r) (Cody–Waite, ln2_hi with trailing
    zeros so that n · ln2_hi is exact); p(r) by Horner with one fma per step (Taylor to
    degree 13 in f64 and 7 in f32 on |r| ≤ ln 2 / 2, or minimax coefficients of a lower
    degree if the f64 bound allows it, generated by a committed script); the result
    `scale_pow2(p, k)`. One instruction sequence per lane, independent of the others.
  - Precision constants through `SimdScalar`'s sealed trait (as the entry points are).
- `src/exp.rs` (new, public): `exp_slice(isa, x, out)`, the analogue of
  `rsqrt::rsqrt_slice`, with the table of formulations and the contract; entry points
  `exp_slice_f32`/`_f64` per ISA, `#[inline(never)]`, dispatched as the rsqrt ones.
- `src/lib.rs`: the module, the crate docs' table, `Sealed::exp_slice`.
- Tests: `tests/exp/` (`main.rs`, `contract.rs`, `invariance.rs`), shaped as `tests/rsqrt/`;
  `src/arch/tests.rs` the layer methods `max` and `scale_pow2` against the scalar layer on
  every ISA.
- docs/design/simd-p2p.md: a new §4.9 "The exponential (Helmholtz CH2.4a)": the
  formulation, the error derivation behind 4 u_T, the domain, the measured errors, the
  operation count. `fmm-simd/CLAUDE.md`: the new public module, its contract and its entry
  points in the inlining check.

## Tests that prove it

All on every ISA the machine offers (`common::isas`, printing those it cannot run).

- **Contract, f32:** every f32 in [x_min, 0] (about 1.1 · 10⁹ values; `#[ignore]`,
  release) against `f64::exp` of the same value rounded to f32's error measure, within
  4 u₃₂ relative; the debug run a strided subset.
- **Contract, f64:** 10⁷ seeded samples, uniform in x over [x_min, 0] and log-uniform in
  |x| over [2⁻⁶⁰, 1] (`#[ignore]`, release; 10⁵ in debug), against a double-double
  reference in the test (the exact reduction n ln 2 in double-double and a Taylor series in
  double-double), within 4 u₆₄ relative.
- **Special values:** ±0 → exactly 1; x_min and its neighbours; x below x_min, −∞ → in
  [0, 2^e_min], not NaN; the reduction's boundaries (x = (n + ½) ln 2 for n near 0 and
  near the domain end).
- **Invariance:** the result of each value the same at every position and slice length,
  bit for bit (as `tests/rsqrt/invariance.rs`).
- **Layer:** `max` and `scale_pow2` on every ISA equal the scalar layer bit for bit.
- **Laplace:** the whole existing suite unchanged (no existing test edited).

## Constraints and risks

- Constraint 1 applies to `nd-fmm-simd` as a whole, but CH2.4a only adds: new trait methods
  and new entry points. No existing method, body or entry point changes, so Laplace's bits
  cannot change; the instruction-for-instruction comparison shows that the generated code
  did not either. No Laplace benchmark is run in CH2.4a (CH2.4b runs D9 and C3S.4).
- Risk: the f64 bound. Taylor degree 13 on |r| ≤ 0.347 truncates at about 0.07 u₆₄ and Horner
  rounds at about 1 u. If the measured error comes near 4 u, a narrower reduction (a table
  of 2^(j/8)) is the fallback, at the cost of a gather.
- Risk: AVX2 has no 64-bit integer conversion; the round-to-nearest constant avoids it (k
  already carries n in its bits).
- f32's e_min: the domain stops at normal results, so FTZ/DAZ settings never matter.
